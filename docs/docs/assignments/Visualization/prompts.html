Chart 1: Variable-Width Column

The 2025 HPI data were summarized by continent. The width of each column represents total population, while the height represents mean HPI across countries within each continent.

hpi_continent <- hpi_2025 %>% group_by(Continent) %>% summarise( population = sum(Population, na.rm = TRUE), mean_hpi = mean(HPI, na.rm = TRUE), .groups = “drop” ) %>% mutate( continent_name = case_when( Continent == 1 ~ “Latin America”, Continent == 2 ~ “N America & Oceania”, Continent == 3 ~ “Western Europe”, Continent == 4 ~ “Middle East & N. Africa”, Continent == 5 ~ “Africa”, Continent == 6 ~ “South Asia”, Continent == 7 ~ “Eastern Europe & Central Asia”, Continent == 8 ~ “East Asia” ) ) %>% arrange(desc(mean_hpi)) %>% mutate( xmax = cumsum(population), xmin = lag(xmax, default = 0), xmid = (xmin + xmax) / 2, continent_name = factor( continent_name, levels = continent_name ) )

#| include: false
