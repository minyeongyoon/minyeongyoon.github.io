The four datasets produce almost identical summary statistics and regression results, but their scatterplots reveal different relationships. Plot 1 shows a relatively linear pattern, whereas Plot 2 demonstrates a nonlinear and curve relationship. Plot 3 contains an extreme outlier, and Plot 4 depends heavily on a single high-leverage observation. These differences illustrate the limitation of relying solely on numerical summaries and regression coefficients. Therefore, analysis should include graphical examination of the data before interpreting model results, as well as diagnostic checks such as residual plots and investigation of influential observations.

# Define elements in plant art
# Each image corresponds to a different axiom, rules, angle and depth

# Leaf of Fall

axiom="X"
rules=list("X"="F-[[X]+X]+F[+FX]-X", "F"="FF")
angle=22.5
depth=6


for (i in 1:depth) axiom=gsubfn(".", rules, axiom)

actions=str_extract_all(axiom, "\\d*\\+|\\d*\\-|F|L|R|\\[|\\]|\\|") %>% unlist

status=data.frame(x=numeric(0), y=numeric(0), alfa=numeric(0))
points=data.frame(x1 = 0, y1 = 0, x2 = NA, y2 = NA, alfa=90, depth=1)

for (action in actions)
{
  if (action=="F")
  {
    x=points[1, "x1"]+cos(points[1, "alfa"]*(pi/180))
    y=points[1, "y1"]+sin(points[1, "alfa"]*(pi/180))
    points[1,"x2"]=x
    points[1,"y2"]=y
    data.frame(x1 = x, y1 = y, x2 = NA, y2 = NA,
               alfa=points[1, "alfa"],
               depth=points[1,"depth"]) %>% rbind(points)->points
  }
  if (action %in% c("+", "-")){
    alfa=points[1, "alfa"]
    points[1, "alfa"]=eval(parse(text=paste0("alfa",action, angle)))
  }
  if(action=="["){
    data.frame(x=points[1, "x1"], y=points[1, "y1"], alfa=points[1, "alfa"]) %>%
      rbind(status) -> status
    points[1, "depth"]=points[1, "depth"]+1
  }

  if(action=="]"){
    depth=points[1, "depth"]
    points[-1,]->points
    data.frame(x1=status[1, "x"], y1=status[1, "y"], x2=NA, y2=NA,
               alfa=status[1, "alfa"],
               depth=depth-1) %>%
      rbind(points) -> points
    status[-1,]->status
  }
}

3. Write a critique on a chart in published work (book/article/news website)

This chart communicates differences in concern about immigration across the selected countries. The countries are ordered by percentage, and the direct labels above the bars make comparisons easy without requiring the reader to estimate values from an axis. The limited use of color and the inclusion of country flags also help distinguish the main data from supporting information. However, the presentation of the rank information at the top is less effective. The circles appear to vary in size according to rank, even though rank is an ordinal measure rather than a continuous quantity. This may imply a stronger quantitative relationship between ranks than actually exists, and the smaller circles also force some rank values, such as 14, 18, and 15, to be placed outside the circles, reducing visual consistency. In addition, the percentage and rank represent different concepts: the percentage can be compared directly across countries, whereas the rank depends on how immigration compares with the other 17 issues within each country. Combining both measures with prominent visual encodings adds unnecessary complexity. A clearer design would retain the ordered bar chart for percentages but display rank as a simple text column or in a separate chart. Using full country names instead of abbreviations such as CL, TR, and DE could also make the chart easier to understand without relying on the flags.
